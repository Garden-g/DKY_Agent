# 大客赢 Accio Work 业务智能体（49 个）

大客赢外贸业务智能体套装覆盖企业 AI 底座、知识库问答、市场与选品、国际站运营、营销素材、客户开发、销售转化和经营管理。当前版本为 `v2.7.4`，支持 Windows 和 macOS，全部智能体统一使用“大客赢”名称与 Logo。

## 安装

1. 打开 [安装提示词](INSTALL_PROMPT.md)，将对应系统的命令发送给 Accio Work。
2. 等待下载、ZIP 摘要校验和安装完成。
3. 完整退出并重新打开 Accio Work，在智能体列表中使用。

安装器一次安装 49 个智能体。已安装同来源旧版时，原位更新模板与私有 Skill，保留原 Agent ID、账号画像和长期记忆，不重复创建；其他智能体不受影响。

## 企业 AI 底座搭建

通过多轮确认、资料读取和必要的公开检索，完成资料盘点、企业定位、产品资料、问答案例、市场画像、行业与准入、竞品定位和知识库入库准备。

内置 8 份 Word 成果与 7 份 Excel 成果，保留完整业务示例和明确的虚构说明。知识库上传、绑定及权限操作需要用户授权；没有真实回执时不能声称生效。日常检索问答交给企业知识库问答智能体。

随完整套装安装，也提供[独立安装说明](install/dakying-enterprise-ai-foundation-agent.txt)。目标环境需要安装并授权所声明的知识库、文档和表格插件。

## 企业知识库问答

企业知识问题必须先使用 `search_kb_file_contents` 或 `get_kb_file_contents` 检索，每次回答列出实际引用文件。首轮读取 20 个候选块，证据不足时扩大至 30，必要时最多 50；未找到证据时明确说明，知识库与 Memory 冲突时提醒用户确认更新。

随完整套装安装，也提供[独立安装说明](install/dakying-enterprise-knowledge-base-qa-agent.txt)。目标环境需要安装并授权 `knowledge-base-plugin`。
